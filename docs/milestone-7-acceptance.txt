M7 acceptance
=============

Configuration schema v3 persists StarBrightness, DiskOpacity, Doppler,
StarDensity, and SkyFlowSpeed. The first three remain 0..100 with defaults
30/90/60; density remains 50..200 percent and sky speed is 0..500 percent,
both defaulting to 100. Schema 2 remains readable with its historical 50..200
percent sky-speed limit. Missing or v1 markers load only the legacy three
fields and force both newer settings to 100. Invalid, zero (including a
partial-save marker), wrong-type, and future markers default all fields.
Schema v3 reads each field independently, so one malformed or out-of-range
field does not discard the other valid v3 values.

All five UI bars are normalized to 0.000..1.000. Brightness, opacity, and
Doppler map linearly to 0..100%; density maps to 50..200%; and sky speed maps
to 0..500%, where 0.200 is the 100% baseline and 1.000 is 500%. `/c` only
saves on OK. A save first writes schema marker 0, writes all five fields in
order, then publishes marker 3. Cancel and close never persist.

Both modes use one `BlackHoleSettings` window class, one five-control layout,
and one schema-v3 persistence path. `/c` opens that class as an independent
configuration window with **OK** and **Cancel**. `/w` opens a normal, resizable
renderer plus an owned non-child floating `BlackHoleSettings` tool window with
**Save** and **Revert**. Its command syntax is standalone, and malformed /p,
/d, or /w invocations are rejected rather than falling through to the
fullscreen screen-saver path.

In `/w`, slider changes immediately alter memory-only rendering. Save persists
and updates the snapshot; Revert and an unsaved close restore the entry
snapshot. Closing the owned floating settings window closes the adjustment
session. The renderer owns one OpenGL context, one full-client draw per frame,
the one-pass fixed 48-step renderer, one draw per frame, and no FBO, texture, or quality tier. At
100% density and sky speed, M6 sky catalogue thresholds and SKY_FLOW_SPEED
timing remain exactly on their baseline paths.
