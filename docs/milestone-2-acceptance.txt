Black Hole Screensaver — Milestone 2 SceneState Seam
=====================================================

Status: implemented as a no-intended-visual-change migration.

This file is plain text because newly created Markdown files are ignored by the
repository policy.

1. Purpose and boundary
-----------------------

Milestone 2 introduces the first host-owned, immutable-per-render-frame
SceneState seam. It does not move the legacy tour, Lissajous pose, breathing
size, DiskLook interpolation, lensing equations, disk equations, or sky layout
math out of the embedded GLSL. Those migrations are deliberately deferred:
host recomputation of their trigonometric, hash, and float-to-int expressions
would not credibly preserve exact current output.

The host owns the frame inputs and sends them through exactly one uploader:

  elapsedSeconds
  resolutionX, resolutionY
  starGain, diskOpacity, doppler
  sceneSeed, skySeed

A SceneState is built only by renderFrame() from its single GetTickCount64()
sample. Normal visible frames reach renderFrame() only after the existing fence
and cooldown gate admits them; the hidden first render also uses this same
path. State is uploaded after glUseProgram() before glDrawArrays(). No state is
built for a skipped timer tick or inside initShader().

2. Compatibility and parity rules
---------------------------------

- The legacy shaderSource C-string is frozen by an LF-normalized SHA-256.
  It contains all current scene derivation and Schwarzschild renderer math and
  must remain unchanged in this milestone.
- Existing iTime, iResolution, uStarGain, uDiskOpacity, uDoppler, and
  uSceneSeed receive the same values. The original per-frame order through
  uDoppler is retained; uSceneSeed moves from one init-time write to the
  centralized per-frame uploader, after those values and before drawing.
- Raw control conversion remains exactly:

    (float)cfg_starBrightness / 100.0f
    (float)cfg_diskOpacity / 100.0f
    (float)cfg_doppler / 100.0f

  M2 does not clamp, validate, migrate, or rewrite registry values. The
  existing shader-side clamps remain authoritative until Milestone 4.
- sceneSeed and skySeed are generated by separate calls and are immutable for
  the run. The legacy shader continues to use sceneSeed for both its tour and
  star layout so the existing output remains unchanged.
- fragHeader declares uSkySeed as the future sky seam. shaderSource deliberately
  does not consume it in M2, so a conforming GLSL compiler may report location
  -1. The uploader treats -1 as valid and skips that write.
- No UBO, texture, FBO, new rendering pass, new GL extension, configuration UI,
  registry schema, quality calibration, or external asset is added.

3. What M2 does not claim
-------------------------

SceneState is a frame-input seam, not yet the complete physical scene model.
It does not make the sky inertial, make camera/body/disk pose host-owned, or
replace the current nonphysical legacy motion. Those are subsequent explicit
milestones. The static verifier proves source and data-flow invariants; it
cannot prove pixel equality on every driver without the future deterministic
GPU capture harness.

4. Automated acceptance
-----------------------

  powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\tools\verify-milestone-2.ps1

The M2 verifier first runs the M1 baseline verifier. It reads
blackhole_screensaver.c directly from immutable pre-M2 commit
166ab817f1052436b89ae4b7c5f61718452e9b25, verifies that commit's reviewed
shaderSource hash, and requires the current host source to equal exactly that
baseline plus the small, explicit M2 SceneState patch. This protects shader
math, registry loading, fence/cooldown helpers, hidden-first-frame ordering,
and all unrelated host regions rather than merely checking independent strings.
CI fetches full Git history for this comparison. The verifier is a development
and CI tool and therefore requires the repository's Git history.

It then checks:

- the unchanged shaderSource block against that immutable pre-M2 source;
- the exact SceneState field list and legacy value expressions;
- centralized upload mappings and active-uniform lookup;
- distinct initialization of sceneSeed and skySeed;
- the inactive-but-guarded uSkySeed reservation;
- state construction/upload ordering in renderFrame(); and
- absence of state construction on the skipped-frame and initShader paths.

5. Manual Windows/OpenGL smoke acceptance
------------------------------------------

1. Build with build.bat.
2. Run /d and confirm a live initialized first frame rather than a black flash.
3. Run /s and /p with a valid preview parent; confirm normal rendering and exit
   behavior through the normal test harness.
4. Open /c; verify the existing three controls still open and persist normally.
5. Check %TEMP%\blackhole_screensaver.log for no shader compile/link failure.
6. Compare the observed visual result with the M1 baseline; M2 has no intended
   visual difference.

6. Next-step gate
-----------------

Milestone 3 changes the canonical shader pipeline and the sky-coordinate
mapping, so it is a visual milestone. After it is implemented and verified,
work must stop for explicit user visual confirmation before any later visual
milestone starts.
